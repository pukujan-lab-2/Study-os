## Summary

P0 live crash: **Explain again ×2** → ErrorBoundary `Cannot read properties of undefined (reading 'type')`.

**Root cause:** `FrameStepper` kept a stale `index` after `adapt(reexplain)` / presentation rotate **shrunk** `teach_frames`, so `frames[index]` was `undefined` and `TeachRenderBox` read `.type`.

Refs #163 · parent #126

## Fix (defense in depth)

| Layer | Change |
| --- | --- |
| `frames.ts` | `isRenderableFrame` / `sanitizeFrames` |
| `FrameStepper` | sanitize + clamp index on shrink |
| `Frame` / `TeachRenderBox` | null-safe; never read `.type` on holes |
| `applyPresentation` | sanitize tutor overlays |
| `presentation._usable_frames` | backend drops untyped frames |
| `Player` | track latest adapt view; filter probe frames |
