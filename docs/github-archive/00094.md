- State: open

- Original: https://github.com/Pukujan-lab/Study-os/issues/94

## Why this matters
The frontend must live under Alex's existing domain. The backend runs at home without opening ports.

## Outcome
On gravebuster: Docker Compose with `api`, `postgres`, `metabase`, and `cloudflared`. The named tunnel publishes `study-api.design-bakery.com` (the zone is already on Cloudflare), and Tailscale stays the admin path. Frontend: a separate Vercel project from `Study-os/web`, plus design-bakery `vercel.json` rewrites for `/study-os` and `/study-os/:path*`, following the existing `/ai-for-good` pattern. CI deploys the API through a pull-based deploy on gravebuster (a systemd timer or Watchtower pulling a GHCR image), with no inbound SSH from CI.

- [ ] The Vercel preview plus rewrites smoke test passes. SSE survives the Cloudflare proxy with heartbeats.
