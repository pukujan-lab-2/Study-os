## Summary

UX upgrades on the live sticks-and-boxes Big O interactive (#185 / #186), grounded on the same validated UX class — not invent-cold.

## What changed

1. **Click-to-place** — highlighted / target box is clickable to place a stick; **Put Next Stick** stays as alternate.
2. **Friendlier n** — intro + slider label use plain language (“work grows as the problem size **n** grows”; “How big the problem is (n)”); still distinguish n = input size vs work = ops.
3. **Default n = 3** (component + lesson frames + `render_text`).
4. **Heat / stress side panel** — calm → warm → melting emoji + gauge as Total Work climbs (O(1) calm → O(n) warmer → O(n²) melting).
5. **Compare-next CTA** — no dead Finished after one mode:
   - O(1) done → “Let's compare that to O(n)” (keeps n, resets sticks)
   - O(n) done at n < 5 → “Try the same rule at n = 5” (makes 3 vs 5 Total Work obvious)
   - O(n) done at n ≥ 5 → “Let's compare that to O(n²)”
   - O(n²) done → **Finished!** only
6. **Scale note (copy only)** — n = 3 vs n = 1 billion example; never render huge box counts.
7. Lesson captions / why_care teach md + design brief updated.
