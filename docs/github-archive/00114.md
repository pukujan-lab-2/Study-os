## Goal
Build (after research) a **Pedagogical Decomposer** that turns a raw DSA (or similar) problem into a teaching sequence matching the golden schema — without requiring Alex to invent the sequence by hand each time.

The golden dataset (SOS-0010, `domains/dsa/sliding-window/golden/dataset/`, #111 / PR #112) captures the *finished* teaching sequence. It does **not** capture *how to invent* that sequence for a new problem. An agent would not automatically break a DSA task into algebra stepwise then conversion without Alex's help.

We need a system that:
1. Finds a good way to solve the problem
2. Auto-decomposes into concept dependencies
3. Orders them pedagogically
4. Assigns representations
5. Emits moves matching the golden schema (`moves.jsonl`)

## Scope (this issue = research + human-eval prototype; no production build)
