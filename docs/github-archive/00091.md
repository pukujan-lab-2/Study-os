# Issue #91: [WebApp] Subject packs beyond DSA: HESI A2 / nursing practice support

- State: open
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/91
- Labels: enhancement

## Why this matters
The second learner is studying for HESI. Study OS semantics (capability states, assistance, transfer, delayed checks) are subject-agnostic, but content and grading are not.

## Outcome
A subject-pack format:
- skill graph;
- item types: MCQ, SATA, ordered prioritization, numeric dosage calculation with a tolerance-graded deterministic generator, short free-text explanation graded by the LLM interpreter;
- rationales hidden until an attempt;
- transfer and holdout item pools.

A first HESI pack uses original or openly licensed content, for example Open RN (CC BY). No proprietary HESI items are copied.

## Acceptance criteria
- [ ] Pack schema validation plus a license field per item. CI rejects items with no license or source.
- [ ] Holdout items are never tutor-visible (tested).
- [ ] Deterministic grading for MCQ, SATA, ordering, and dosage, with property tests (for example, unit conversions round-trip).
