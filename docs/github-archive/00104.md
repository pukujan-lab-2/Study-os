- State: open

Parent: #82 (web app epic) · Related: #101 · Dependencies: none

## Goal
An onboarding flow that gets a new learner from landing to a first small win in about 60 seconds, designed from research on how production learning apps do it.

## Scope
1. **Research first:** a short cited note in `docs/webapp/` on onboarding in Duolingo, Brilliant, Khan Academy, Headspace, Anki-based apps and similar: goal picking, placement/diagnostic step, time commitment, the first-win moment, when signup is asked for, and personalisation. Also a brief UX pattern pass.
2. **Design:** choose study lanes, set a goal and schedule, a quick placement check, then the first micro-lesson.
3. **Build** (prototype) in the React app plus any API needed (goal/schedule/lane preferences, placement result stored as evidence, never as a mastery claim).
- Out of scope: push notifications, payments.
