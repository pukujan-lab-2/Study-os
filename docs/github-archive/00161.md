# Issue #161: Research-backed teach visuals for every lesson/step (provenance + vision verify)

- State: open
- Opened by Pukujan on 2026-09-27
- Original: https://github.com/Pukujan-lab/Study-os/issues/161

Parent: #126

## Goal
Stop invent-first CSS/SVG metaphors. Ground every teach / explain / worked visual in external research and real study-program artifacts, store with provenance in the lesson DB, and use InferHub vision only to verify the live render matches the curated reference.

## Why
Alex (2026-09-27 live): growth-curve style is clearer than invented stick workers; two-line slow-vs-fast undersells Big O; wants multi-class charts (O(1) vs O(log n) vs O(n) vs O(n²)); must apply to **all problems and each step**, not one slide. UX problem, not coding theater.

## Scope
1. Inventory every player lesson + teach/explain/worked step.
2. Map each step to a research visual type with citations (e.g. Big O → multi-curve cheatsheet family; fractions → number line per Hamdan/Gunderson, Fuchs, IES Teaching Fractions Toolkit).
3. Curate versioned assets (OSS / public-domain / citable figures) + provenance JSON in lesson DB / content pack.
4. TeachRenderBox (or successor) consumes curated assets — no cold invent.
5. InferHub cheap vision: reference-match gate only.
6. Strip numbered 1.2.3. caption spam from teach copy (existing A19).
7. Docs: ops brief for agents (research-first, invent forbidden).

## Out of scope
- Inventing new metaphor stick figures without a research source
- Vision generating diagrams from scratch
- Personal study-log content

## Done when
- [ ] Catalog map checked into repo (lesson × step → visual type + source URL/cite)
- [ ] Asset pack + provenance for at least Big O Why + fractions teach/explain/worked
- [ ] Remaining player lessons mapped; assets landed or explicitly queued with issue links
- [ ] Live player shows multi-class Big O chart (not slow-vs-fast only) and number-line-first fractions where research requires
- [ ] Vision verify job (or scout) fails when render drifts from curated reference
- [ ] Policy doc + agent brief; PRs link this issue + #126
- [ ] Ultrafast + Playwright FE checks green before claim-done

## References (starter)
- Big-O chart family: bigocheatsheet / bigochart.com / ro31337/bigoposter / course growth-rate plots
- Fractions number line: Hamdan & Gunderson (causal RCT); Fuchs et al. intervention; IES REL Teaching Fractions Toolkit Module 1
