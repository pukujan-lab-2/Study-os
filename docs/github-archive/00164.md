﻿## Unblocked: human feedback calibration pack is on `main`

Claim: #164's done-when (schema + seed + docs) is landed. PR #166 was merged to `main` as the squash commit whose message is `feat(ops): human feedback calibration pack (Refs #164 #126) (#166)` at 2026-09-27T12:49Z.

The PR was blocked by three CI failures, not the two that were reported up front. The third was masked.

### 1. `Validate research harness` - bespoke session manifest (the real blocker)
`sessions/2026-09-27/big-o-ux-calibration/manifest.json` was hand-written in a shape that `schemas/session-manifest.schema.json` rejects five ways: missing `schema_version`, `started_at`, `raw_artifacts`, and `source.capture_method`, plus five unexpected top-level keys, because that schema sets `additionalProperties: false`.

Fix was to correct the data, not the validator: rewrote the manifest to the canonical shape. `schemas/session-manifest.schema.json` is untouched, and the file was **not** added to `LEGACY_CALIBRATION_MANIFEST`. The "self_reported, not mastery evidence" wording is preserved inside `notes` (the schema forbids a top-level `evidence_boundary`), `derived/findings.md` stays out of `raw_artifacts` to keep observed/self_reported/derived distinct, and the session has no `raw/` directory so the public data boundary check is unaffected.

### 2. Same job, masked - Ruff lint on the pack's own helper
`tools/append_human_feedback.py` imported `datetime.timezone` without using it (Ruff F401). This never showed in the original CI output because failure 1 aborted the job before the lint step ran; it only surfaced once the manifest was fixed. Removed the unused import.

### 3. `Playwright + vision gate` - stale branch, not a defect
The two `M-regen` failures came from a spec that still waited on `/tutor` by name after `main` moved "Explain again" to the deterministic authored-frame swap (`POST /adapt`, `kind=reexplain`). `main` had already fixed this in the e2e change landed under #174. Cleared by merging `main`; no spec or product code was edited for it.
