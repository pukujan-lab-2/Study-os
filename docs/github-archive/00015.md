## Adds

- `schemas/episode-plan.schema.json`
  - ordered atomic steps
  - explicit complexity stages
  - entry/remediation assistance
  - `pass_unaided` advancement gate
- `domains/dsa/running-extrema/episode-plan.v0.1.json`
  - seven-step progression from value comparison through blank implementation
  - explicit scaffolded then faded update-order stages
- `study_os.adaptive.scaffold`
  - probe current step when behavioral evidence is missing
  - fail/partial -> remediate same step
  - pass_supported -> fade assistance and retest same step
  - pass_unaided -> advance exactly one step
  - final pass -> episode-complete candidate only; cannot award transfer/delayed mastery
- tests against the real curriculum item bank and episode plan

## Boundaries

- shadow proposals only
- no DB/checkpoint mutation
- no new semantic tool
- no conversational/self-report-only advancement
- transfer and maintenance phases remain outside this controller
- transfer/delayed capability promotion remains a separate evidence gate
