# Issue #78: [Infra] Make Study OS the validated owner of its continuity state (PCM overlay + pinned CGM adapter)

- State: closed (2026-09-24)
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/78

## Why this matters

Study OS already owns its project facts in `AGENTS.md`, `PROJECT_MANIFEST.yaml`, `docs/PROJECT_CHARTER.md`, and `docs/HANDOFF.md`, but nothing machine-checkable tells an agent that **this repository** is the authority and that `project-continuity-modules` (PCM) and `content-generation-modules` (CGM) are only pinned helpers. Without that, a fresh agent can treat helper state, chat memory, or another repository as the source of truth, or read a helper's moving `main`.

## Outcome

Study OS is the declared, validated owner of its continuity and human-facing content state, and uses the two helpers only through pinned, documented adoption conventions:

- PCM mature-repository overlay (`docs/TARGET_ADOPTION.md`): existing documents stay authoritative, no parallel PROJECT/CURRENT files.
- CGM target adapter (`.content-system/`) pinned to an exact helper commit.

## Scope

In scope:
- `.continuity/config.json`, exact copy of PCM `schemas/v1/**`, a `tasks/` directory with this task's projection;
- single-line `continuity:project` marker in `docs/PROJECT_CHARTER.md` and `continuity:current` marker in `docs/HANDOFF.md` (no semantic change);
- `.content-system/` adapter with helper pin and project-brief v2 claims pinned to Study OS revisions;
- `AGENTS.md` / `PROJECT_MANIFEST.yaml` helper-ownership section and paths;
- a deterministic test for the adoption invariants.

Out of scope: runtime/schema/MCP changes, README rewrite, generated imagery (deferred by `AGENTS.md` until R0), any data from private repositories.

## Acceptance criteria

- [ ] `continuity preflight --root <Study-os>` at the pinned PCM commit prints `MODE: TARGET_VALID`.
- [ ] `schemas/v1/**` byte-identical to the pinned PCM commit.
- [ ] `.content-system/system-version.json` pins CGM repository, version, and full commit; the pinned CGM validator result is recorded (including any remaining gap).
- [ ] `AGENTS.md` states Study OS is authoritative and helpers are pinned tooling only.
- [ ] Existing Study OS checks (`validate_repo.py`, engineering baseline, full unittest suite) stay green, plus a new adoption test.
- [ ] No private-repository content is copied.
