# Issue #92: [WebApp] Agent-vs-agent eval harness: simulated learners exercise the tutor and check golden teaching rules

- State: open
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/92
- Labels: enhancement

## Why this matters
Checking tutor behavior by hand is slow. Simulated learner agents with scripted misconceptions can exercise the full session loop cheaply and automatically. The results count as system evaluation only, never learner evidence (manifest: `synthetic_simulation_equals_human_learning_effect` is prohibited).

## Outcome
A persona library: novice, off-by-one, guesser, answer-seeker/jailbreaker, partial-knower, frustrated quitter, test-anxious HESI learner, prompt injector. It runs three tiers:
- T0: offline, recorded LLM fixtures, runs in CI, no cost;
- T1: nightly live cheap routes;
- T2: pre-release.

Each turn is checked by deterministic violation detectors that mirror `study-os-benchmarker` codes, plus web-specific codes.

## Acceptance criteria
- [ ] Detectors for ANSWER_REVEAL_FORBIDDEN, MASTERY_CLAIM, MULTI_QUESTION, MULTI_RELATION, CHART_DROPPED, RETRY_SAME_EXAMPLE, HELP_NOT_FADED, and ILLEGAL_NEXT_NODE. Each detector is killed by a targeted mutation.
- [ ] T0 runs in CI in under 2 minutes. T1 has a per-run budget cap and writes a scorecard artifact.
