## Source-quality boundary

Publication does **not** claim that this is the complete underlying ChatGPT conversation. The exporter itself says `PARTIAL / NOT ESTABLISHED` and warns that repeated scroll sweeps did not establish a stable turn set.

The source also contains assistant messages embedding earlier transcript Markdown. Luna must not treat every nested `## User` / `## Assistant` heading as a new outer turn.

## Recovery contract

Luna must:

1. reconstruct and hash-verify the exact Markdown;
2. back up `/root/.study-os` before mutation;
3. preserve the reconstructed source itself as immutable local Study OS evidence;
4. review/extract only real outer turns;
5. conservatively map supported ranges to `subject-001` historical sessions;
6. reconcile only missing source turns;
7. rerun reconciliation and prove zero additional writes;
8. prove attempts/events/checkpoints/live post-fix messages were not overwritten;
9. verify hashes, doctor and backup/restore;
10. only afterward create reviewed source-linked live-learning events/episodes;
11. report `source_exhausted` separately from `conversation_complete`.
