## Recommended stack (short)
- **STT:** browser Moonshine or Whisper `small.en` with lesson hotwords → gravebuster `faster-whisper small.en` + hotwords (or Parakeet-TDT int8) → editable transcript + phonetic/fuzzy/embedding/"did you mean" cascade → Jev only when unsure
- **TTS:** always-warm Kokoro (incl. original style blend); lazy Pocket TTS (CC0/CC-BY voices) and Piper; Chatterbox only if it clears the gravebuster latency bar; exclude NC weights (F5, XTTS)
- **Not now:** per-user LoRA; ML denoisers in front of ASR by default
