Event-triggered continuous deploy: every push/merge to `main` updates live https://study.design-bakery.com on gravebuster without a manual SSH step.

## Context
- Repo `allow_auto_merge` already **true**; `main` requires Validate research harness + Python 3.11 (strict).
- PCM: CI green → auto-merge (Alex 2026-09-26).
- Today deploy is manual per `deploy/README.md`. No deploy workflow exists (only `ci.yml` + `pir-mutation.yml`).
- Host: `/srv/study-os/{app,docker-compose.yml,.env,pg,backups}`; image `study-os-api:local` from `deploy/Dockerfile`.
- Note: `/srv/study-os/app` may not be a git checkout (confirm on host).

## Done-when
1. GitHub Actions on `push` to `main` that updates the host to the merged SHA, `docker compose up -d --build`, health-checks localhost + public URL, fails if unhealthy.
2. Secrets documented (never committed).
3. `deploy/README.md`: CD primary; manual fallback.
4. PR `Refs #<this>` with `gh pr merge --squash --auto`.
5. One successful CD proof (push or `workflow_dispatch`).
