## Root cause

Two assertions encoded the *old implementation* rather than the *relation*:

1. **Transport.** Asserting `/tutor` by name made this a transport test. `/adapt` and `/tutor` both re-render the same step; the relation is "a re-render happens and nothing is posted". Now either is accepted — a silent no-op firing no request still fails.
2. **Observable change.** `innerText` was compared before/after. Explain again swaps the teach *diagram* (authored frame reserve), and a `fraction_bar` frame renders no text — so `innerText` is byte-identical across a real re-render. Now `innerHTML` is compared.
