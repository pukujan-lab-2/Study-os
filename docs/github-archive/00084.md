# Issue #84: [WebApp] Frontend: React app served from gravebuster at study.design-bakery.com with a quiz-game lesson player

- State: open
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/84
- Labels: enhancement

## Why this matters
Learners need a fast, playful surface. It renders controller-authored steps and persistent charts, and does not invent pedagogy.

## Outcome
A Vite + React + TypeScript app in `web/`. It is deployed as its own Vercel project with `base: '/study-os/'` and a router basename of `/study-os`, and is served under `design-bakery.com/study-os` through a design-bakery rewrite. Features:
- login;
- a home "quest map" of skills showing capability states;
- a lesson player: one step, one picture, one tiny question;
- a persistent SVG box/array chart rendered from controller chart specs;
- an MCQ/SATA player for HESI;
- one-tap reaction buttons (helped / confused / frustrated);
- a session summary that never claims mastery.

## Acceptance criteria
- [ ] Every learner-visible chart comes from a deterministic chart spec in the API response. The frontend holds no answer data for unanswered probes (checked by a test that inspects the API payload).
- [ ] Deep links and asset URLs work under `/study-os/*` through the rewrite (Playwright smoke test against the preview URL).
- [ ] No third-party trackers or fonts that phone home. The CSP allows only self and the API origin.
- [ ] Accessibility: keyboard-only play works, and charts have text alternatives.
