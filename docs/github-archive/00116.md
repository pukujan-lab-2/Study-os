## Summary
Critical live fix for study.design-bakery.com.

**Pet empty glow:** `/mascot/*.webp` was served as `application/octet-stream`. With `X-Content-Type-Options: nosniff`, browsers blocked the sprite in CSS `background-image`, leaving only the hover aura. Fix: register `image/webp`, mount `/mascot` and `/review/decomposer/data` as `StaticFiles` **before** the SPA catch-all, and set explicit `media_type` on `FileResponse`.

**DSA first step:** BoxIndex now draws cell chrome; first teach frame shows positions; empty probe card is not rendered; LessonMap is compact step chips (no Mermaid zoom theater). Pet hover/Hide/tip toned down.
