## Goal

Ship a Study-os interactive teach visual in the **sticks-and-boxes Big O** UX class — learner acts as the computer, placing sticks into labeled boxes under O(1) / O(n) / O(n²) rules — so growth cost is felt as counted work, not only read as a static chart.

## Scope

### In scope
1. Interactive teach visual (TeachRenderBox / `interactive_visual` frame) where the **learner performs ops**.
2. Complexity modes at minimum:
   - **O(1) Constant** — put 1 stick in the first box
   - **O(n) Linear** — put 1 stick in each box
   - **O(n²) Quadratic** — cross-pair every box with every box (step labels like `Cross-Pairing Box i × Box j`)
3. **n control** (slider / equivalent) that rescales boxes and required stick count.
4. **Ops counter / stats row**: Complexity, Sticks Placed `x/y`, Total Work `ops`.
5. Primary controls: **Put Next Stick** / **Finished!** / **Reset**.
6. Visual grammar from exemplar: stick dispenser + labeled boxes + active-target highlight + (for O(n²)) cross-pair step labels.
7. Short design note (this issue + optional `docs/research/` brief) + provenance note linking the Gemini exemplar.
8. Wire into Big O lesson step map when ready (player lesson `big-o-growth-families` or successor).

### Out of scope (this issue)
- Full pixel parity with Gemini chrome / fonts / dark-theme cosmetics.
- Replacing the curated multi-class growth-curve default teach (#161).
- O(log n) interactive mode (nice-to-have later).
- Auto-play / animation-only demos where the learner does not perform ops.
- Implementing the full game in the filing PR unless a trivial thin spike is already in hand (prefer issue + design note first).

## Design note (short)

| Control / surface | Behavior |
| --- | --- |
| Complexity dropdown | Selects rule that drives next-stick target(s) and total stick budget |
| n slider | Sets box count; recomputes target sticks: O(1)→1, O(n)→n, O(n²)→n² |
| Put Next Stick | Learner advances one op; dispenser → active box; stats tick |
| Finished! | Shown when `sticks placed == target`; confirms completion |
| Reset | Clears sticks / step label; keeps n + complexity |
| Stats | Complexity · Sticks Placed x/y · Total Work ops |

**Pedagogy intent:** learner *is* the computer. Feeling “4 ops for n=2 under O(n²)” vs “2 ops under O(n)” vs “1 op under O(1)” is the learning event. Pair later with the multi-class growth chart so the curve family is not orphaned.

**Integration sketch:** new `visual_type` e.g. `sticks_boxes_complexity` (or `interactive_ops_boxes`) in teach-visual pack; provenance entry citing this issue + Gemini exemplar screenshots; TeachRenderBox mounts island; InferHub vision verifies against curated reference frames (not free-generate).
