# Issue #95: [WebApp] Privacy and data boundary: learning and UX data only, no personal data

- State: open
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/95
- Labels: enhancement

## Why this matters
Alex requires that no personal data is captured. The repo is public, so the private evidence rules (`docs/DATA_POLICY.md`) extend to the hosted app.

## Outcome
- A data inventory and allowlist.
- A PII scrubber on all free-text before storage and before LLM calls: emails, phones, URLs, addresses, and names via a deny/heuristic list.
- No IP addresses or user agents stored (they are dropped at the API, and Cloudflare logs are not exported).
- Retention rules, learner export and delete, and LLM calls that send only the minimum context (never account ids).

## Acceptance criteria
- [ ] A property test: generated PII strings never appear in any persisted table or in LLM request bodies.
- [ ] The schema allowlist test fails on new personal-data columns.
- [ ] Private-repository content is never ingested.
