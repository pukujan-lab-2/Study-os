## Recovery contract

Luna must:

1. verify the private source hash;
2. backup the live runtime;
3. preserve original MD bytes privately as immutable Study OS evidence;
4. reconstruct only reviewed outer turns;
5. keep ambiguous order/session mapping unresolved rather than guess;
6. reconcile only missing turns;
7. rerun to prove idempotency;
8. prove existing attempts/events/checkpoints were not overwritten;
9. create source-linked reviewed live-learning episodes only after raw recovery is stable;
10. report `source_exhausted` separately from `conversation_complete`.

No runtime code or learner data is changed by this PR.
