# Issue #191: UX: sticks-boxes click-to-place, friendlier n, heat emotion, compare-next CTA

- State: open
- Opened by Pukujan on 2026-09-27
- Original: https://github.com/Pukujan-lab/Study-os/issues/191

Parent: #185 · Hub: #126

## Goal

UX upgrades on the live sticks-and-boxes Big O interactive (#185 / #186) without inventing a new metaphor.

## In scope

1. **Click-to-place** — point-and-click the highlighted / target box to place a stick; keep **Put Next Stick** as an alternate.
2. **Friendlier first-screen n** — avoid bare “n” alone. Plain language first (e.g. work grows as the problem size **n** grows); still distinguish n = input size vs work = ops.
3. **Default n = 3** (not 2).
4. **Side heat / stress visual** — simple CSS/SVG emotion next to the game that calms → warms → melts as Total Work climbs.
5. **Compare-next CTA** — when a mode completes, do **not** leave only a dead **Finished!** Primary CTA advances O(1)→O(n); after O(n) at n<5 offer **try n=5** (keeps O(n), resets sticks) so 3 vs 5 Total Work is obvious; then O(n²). **Finished!** only when all modes done.
6. **Scale note (copy only)** — n=3 vs n=1 billion as an example of work explosion; **do not** render a billion boxes.
7. Theme: easiest way to show work growing / computer work exploding as boxes+sticks grow.

## Out of scope

- Replacing the multi-class growth_curve default teach
- New complexity modes / invent-cold metaphors
