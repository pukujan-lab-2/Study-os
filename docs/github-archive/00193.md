# Issue #193: fix(player): Big O glossary — drop Work (ops); prefer steps / how much work

- State: open

Parent hub: #126 · Related: #185 #189

## Problem (live Pukujan feedback)

"Work (ops)" is bad learner language on first Big O screens. Prefer plain terms.

## Deterministic glossary (teach + sticks-boxes)

| Term | Plain meaning |
| --- | --- |
| **n** | how big the problem is (how many items) |
| **work / steps** | how many steps the computer takes |

Rules:
- Do **not** lead with `ops` or `Work (ops)` on first screens.
- Prefer **steps** or **how much work**.
- Stats label **Total Work** → **Steps** (or **How many steps**).
- Value suffix `{n} ops` → `{n} steps` (or bare count under Steps label).

## Scope (scan + rewrite)

2. `SticksBoxesComplexity` stats row (`Total Work` / `ops`).
3. `why_care` expandable hint if it still says ops (keep "work" if already plain).

5. Optional design-note alignment in `docs/research/teach-visuals/STICKS_BOXES_BIG_O.md` (learner-facing wording). Leave internal type alias `interactive_ops_boxes` alone.
