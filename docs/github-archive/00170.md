## Summary

Full **switchable design system** for Study OS chrome/UI (Refs **#165**, parent **#126**).

Pukujan hates bright lavender → **dark slate default**. Not a one-off dark CSS dump: palette packs, typography, mood + density presets, all via design tokens + `ThemeProvider`.

**Out of scope (per #165):** curated teach image renders + teacher pet/bot sprites. Theme skins chrome/UI only; chart/SVG widgets consume tokens so dark stays readable.
