## Purpose

This issue is the initial project log for Study OS.

The first vertical slice is an instrumented DSA learning system for Subject 001, beginning with Sliding Window in Python. The goal is not to build another static DSA course. The goal is to observe **representation-transition failures**, change the representation/operation, and measure whether the intervention produces immediate performance, assistance-free reconstruction, transfer, and delayed retention.

## Project boundary

Canonical project definition: [`docs/PROJECT_BOUNDARY.md`](../blob/main/docs/PROJECT_BOUNDARY.md)

Current state: [`docs/CURRENT_STATE.md`](../blob/main/docs/CURRENT_STATE.md)

### Atomic unit

A **learning episode**, not a chat or course chapter:

`learner state -> task -> attempt -> failure/uncertainty -> intervention -> re-attempt -> assessment -> transfer/retention`

### Evidence classes

Keep separate:

- **Observed** — answers, scores, hints, attempts, timings, transcript spans.
- **Self-reported** — what the learner says is confusing/helpful and why.
- **Derived** — model/system interpretation of the likely learning failure.

Derived evidence must never silently become ground truth.

## FOSSIL decision

See [`docs/FOSSIL_INTEGRATION.md`](../blob/main/docs/FOSSIL_INTEGRATION.md).

**Decision:** Study OS owns a dedicated learning schema. FOSSIL is an optional export/promotion target, not a required runtime dependency.

Canonical path:

`raw transcript -> Study OS events/episodes -> learner/lesson state -> optional FOSSIL export`

Do not send every learning micro-event through FOSSIL ingest. Promote selected durable artifacts later: curated trajectories, lesson hypotheses, validated domain knowledge, and research conclusions.

## Research questions

1. Can we reliably identify the representation transition at which the learner is failing?
2. Which representation operations produce measurable improvement for that transition?
3. Does self-reported understanding agree with behavioral evidence?
4. Does improvement survive assistance removal?
5. Does it transfer to a changed surface problem?
6. Does it persist after delay?
7. Can a repeated N=1 procedure produce a reusable learning policy without overgeneralizing from one subject?

## Constraint

Do not expand to many DSA patterns or multimodal video generation until the evidence loop works end-to-end on one concept family.
