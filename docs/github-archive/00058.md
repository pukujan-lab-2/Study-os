## Key architecture decision

The existing schema already contains the preferred MVP substrate:

`EvidenceStore + raw_artifacts + messages + idempotency_records`

The repair therefore defaults to **no migration** and adds the missing retry-safe semantic source-turn operation rather than inventing a second transcript database.

ADR-0015 authorizes one bounded MCP semantic capability (preferred name `append_conversation_turn`) and a versioned current surface, while preserving all existing tool semantics and prohibiting generic file/SQL/shell mutation.
