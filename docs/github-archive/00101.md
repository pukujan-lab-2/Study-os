# Issue #101: SOS-0005 Lesson player redesign: golden-faithful micro-steps, visuals, tutor chat, adaptive re-explanation

- State: open
- Opened by Pukujan on 2026-09-24
- Original: https://github.com/Pukujan-lab/Study-os/issues/101

Parent: #82 (web app epic) · Dependencies: none (builds on #99 / PR #100 slice 1)

## Goal
Produce a redesigned lesson player **prototype** (React + API) with screenshots for Alex's approval. Not merged to main and not deployed to production until Alex approves.

## Why: Alex's feedback on the live app (paraphrased)
1. The UI and UX are poor: the HESI fractions lesson is a wall of text followed by a 4-option MCQ with "That helped / I'm confused / Too easy" chips.
2. The worked example is weak.
3. There is no LLM chat interaction. The app is supposed to be LLM-interactive, not pick-one-of-four.
4. There is no simple teaching chart or visual, and the LLM never changes the explanation.
5. It doesn't follow the transcript/goldens (one small idea per step, a concrete visual, predict before being told, react to the actual answer, re-explain in a different representation, fade help, then a quiz with help removed).

## Scope
- Micro-step lesson player: 1-3 sentences per screen plus an interactive/animated visual (fraction bars/area models for fractions; box/index array with a moving window for sliding window).
- Learner answers by typing, predicting, or manipulating the visual. MCQ only where it truly fits.
- Always-available tutor chat (side panel on desktop, bottom sheet on mobile). Grounded in the current step and the learner's history; re-explains in a different representation; never leaks answers during assessment; routes through the existing decision cascade (rules → Jev via OpenRouter → glm-5.3 / deepseek fallback via InferHub); every decision logged.
- "I'm confused" and wrong answers trigger a real adaptive re-explanation (a smaller step or a visual).
- Clear progress (a step map), clean mobile-first visual design.
- Content: a HESI fractions golden-style design note (draft, pending Alex's review) as the first HESI exemplar; the DSA sliding-window lesson rendered faithfully from the existing PIR steps and checked step by step against the goldens and the conformance oracle.

Out of scope: production deploy, merge to main, other HESI topics.
