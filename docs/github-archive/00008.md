## Summary

Refs #5

Adds the P1 network/transport layer needed to connect the accepted local Study OS runtime to ChatGPT without redesigning learner semantics or exposing WSL publicly.

### Transport

- keeps the accepted dependency-free stdio MCP boundary intact;
- adds optional `mcp==2.0.0` Streamable HTTP support;
- adds a stable `mcp-http` CLI launcher fixed to `127.0.0.1`;
- requires host-local `STUDY_OS_MCP_BEARER_TOKEN` before MCP parsing/dispatch;
- exposes only `/mcp`, with no parallel health/admin/OpenAPI/SQL/shell/filesystem surface;
- bounds MCP request bodies to 1 MiB;
- preserves MCP SDK Host/Origin transport-security defaults for production;
- delegates all 13 network tools to the existing P0 semantic boundary/service.

### P1 validation added

- exact 13-tool network allowlist;
- missing/wrong bearer -> HTTP 401 before tool dispatch;
- valid bearer -> MCP tool discovery;
- no bearer reflection;
- non-MCP route isolation;
- non-loopback bind rejection;
- fresh MCP client resumes the same checkpoint after service restart and performs a subsequent write/checkpoint;
- sanitized `tools/verify_mcp_endpoint.py` for local/tunnel edge verification.
