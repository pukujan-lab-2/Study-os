## Purpose

Advance Issue #10 P2F with the first auditable representation-policy selector over an already-selected competency/task.

## Policy boundary

The selector ranks `(task, representation, operation, assistance)` tuples only after upstream task selection. It cannot change the competency/task, exceed the assistance ceiling, or use a representation family not declared by the task.

## Scoring

Explicit shadow-only heuristic components:

- target-bottleneck match
- persistence-weighted behavioral effect across immediate/faded/transfer/delayed windows
- small exploration bonus for untested/sparsely tested representations
- recent-exposure penalty

Persistent effects receive more credit than immediate-only effects. Behavioral outcome scores require canonical evidence IDs. Self-report is not an input to the score.

## Hard gates

- same selected task
- same target competency
- representation family allowed by selected task
- semantic fidelity validated
- assistance target <= upstream ceiling

## Tests

- persistent behavioral effect beats a higher immediate-only score
- untested candidate receives exploration value without fake behavioral effect
- semantic-invalid, wrong-task, disallowed-family, and over-assistance candidates are excluded
- recent exposure is penalized
- no fixed learning-style field exists
- policy remains shadow-only and instruction/fading bounded

## Boundaries

- no canonical state mutation
- no live authority
- no fixed visual/auditory learner profiles
- weights are provisional and explicitly marked uncalibrated

Advances #10 P2F and the representation portion of the shadow bake-off.
