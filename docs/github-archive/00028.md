This is a deliberately narrow E4 verification slice. It adds an independent in-memory event reference model with no SQLite/filesystem/MCP/production-helper dependencies, then runs generated operation streams against both the model and the real runtime.

Covered externally meaningful semantics:
- first durable event write;
- exact idempotent retry;
- conflicting idempotency-key reuse;
- service restart durability;
- durable event cardinality;
- stable event identity on exact retry;
- continuous runtime health.

This does not change runtime behavior, schema, deployment, secrets, adaptive authority, or the exact 13-tool MCP semantic boundary. It is the first bounded E4 slice, not completion of E4.
