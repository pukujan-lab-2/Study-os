## What

Fixes the last open Playwright UX defect on the live guest surface: **A13 companion chat ack** (`P1`, "no chat ack within 20s — silent forever?").

## Root cause (measured, not guessed)

The pending "thinking" bubble rendered only a Sprite image plus three **empty** indicator spans, so it contributed **no DOM text**. The tutor reply call is genuinely slow and variable:

| live sample | tutor latency | observable ack |
| --- | --- | --- |
| 1 | 20.4s | 20474ms — **fail** |
| 2 | 23.0s | 23346ms — **fail** |
| 3 | 9.0s | 9042ms — pass |
| 4 | 9.8s | 9820ms — pass |

The reply itself was always correct; the fallback path already worked. The defect is purely that **nothing observable happened** while the request was in flight, violating the product-truth oracle (`click -> observable change within 3s`, PDD §3).

## Fix

Render a visible `Thinking…` label in the pending bubble so the pending ack is observable on its own, independent of tutor latency. The decorative typing dots become `aria-hidden`; the label carries the text.

## Tests

- `web/src/player/CompanionPanel.ack.test.tsx` — new RED-first unit test that holds the tutor request pending **forever** and asserts an observable ack exists anyway. Fails on the old markup, passes now.
- `web/e2e/ux-defect-controls.spec.ts` — the chat gate now asserts an ack within **3s** (previously: any bubble within 20s, which the old silent behaviour could still satisfy whenever the reply happened to be fast) and then that the real reply lands.
