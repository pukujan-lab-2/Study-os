## What this is
Docs-only spec for turning Study OS into a hosted web app (`design-bakery.com/study-os` frontend, backend and DB on `gravebuster`) for two real learners (DSA and HESI). Start at `docs/webapp/README.md`.

- **Research question:** what to build, and how, so the web surface keeps ADR-0016 deterministic control, captures learning and UX data without personal data, and scales cheaply.
- **Architecture:** lessons are precompiled PIR step graphs served with no LLM call. The LLM is only an interpreter (free-text grading, misconception diagnosis, rewriting a failed step). Its output passes controller validation, and good generations are promoted back into the graph after review.
- **Contents:** research with sources; architecture; property-driven invariants per component; session and product success/fail conditions; data model, including UX signals and learner-memory scope rules; auth; hosting; analytics (a plain Power BI answer); LLM route with price snapshot and live probe results; agent-vs-agent eval design; phased build plan with a thin first slice; the decisions and credentials needed from Alex.

## Deep-research report
The companion report is imported as `docs/webapp/DEEP_RESEARCH.md`; a learner-identifying phrase and local paths were removed. Adopted decisions are listed in `RESEARCH.md` §0:
- rules first;
- hosted Jev for grading and misconception choice (eval-lab blind 89.87%, about $0.042/1M input);
- Laya-421M on gravebuster only for calibrated low-stakes affect signals;
- a frontier LLM (IRE `cb/glm-5.3`) only on low confidence and for rewriting failed steps;
- deterministic next step (rules + pyBKT + FSRS, bandit later);
- xAPI-shaped events + Metabase + a PostHog UX mirror, with Power BI for aggregates only;
- day-one decision logging, 5% audit sampling, and switch criteria (fine-tune / harness / rule).

## Known limitations

  - grade/misconception/wants-answer/frustration calls all worked (`score` criteria must be an ordered array);

  - each call took 0.16–0.26 s, and the model resolved to `typesafe/jev-1.13-20260917`.
  See `LLM_ROUTE.md` §5a.
