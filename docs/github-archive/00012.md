## Purpose

Advance Issue #10 with an interpretable CAT/IRT donor slice behind the existing shadow `LearnerSnapshot -> DecisionProposal` boundary.

## Adds

- standard 2PL IRT predicted-success calculation
- standard 2PL Fisher information calculation
- diagnostic maximum-Fisher-information selector (catsim-style donor mechanism)
- instructional target-success selector, defaulting to 0.70 predicted success
- exposure-limit hard exclusions before ranking
- frozen shared item-bank fixture
- tests proving the same bank yields different best items for diagnostic information vs instructional/ZPD fit
- deterministic replay and formula reference tests

## Architecture boundary

- no direct SQLite/checkpoint access
- no new semantic tools
- no live authority
- no learner-ability estimation from raw history yet; `ability_theta` is an explicit derived input
- no claim that 0.70 is universally optimal; it is a testable target parameter
- no external CAT dependency yet; this reproduces the small interpretable formulas before deciding whether to wrap catsim/EduCAT
