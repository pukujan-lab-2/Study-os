## Problem

Why **Explain again → sticks-and-boxes** stacks too much text *around* the game (not the game itself):

- teach paragraphs defining n/work
- expandable hint (curve-oriented)
- in-component intro (“You are the computer…”)
- figcaption / footer tip (“You place the sticks…”)
- meta line “Explain again opens sticks-and-boxes”

Cognitive load vs golden tutor (ONE concept per turn; no text walls; 2–4 short sentences max; when interactive fills the step, teach is one short line or empty).

## Target (Why sticks-boxes view)

At most **one short teach line** above the game, e.g.

> You are the computer — put sticks and watch steps grow.

+ game controls. Definitions of **n** stay on prior middle frames and/or one collapsed expandable — not all at once with the interactive.

## Scope

1. Slim `why_care` default `teach.md` (drop “Explain again opens…” meta).
2. Add `explain_md` (short line) used when Explain again opens the interactive.
3. Remove sticks frame captions that restate the UI; remove in-component intro.
4. Hide curve expandable hint while sticks-boxes fills the card (or keep collapsed-only if cheaper).
5. Document golden-density surround rule (memory-worthy) in `STICKS_BOXES_BIG_O.md` + human-feedback calibration note.
6. Report before/after word count around the game.

## Out of scope

Game mechanics / click-to-place / heat panel (see #191 / PR #192).

## Done when

- [ ] Sticks-boxes Explain view ≤ ~1 short teach line + controls
- [ ] No redundant caption/intro restating the game
- [ ] n definitions not dumped alongside the interactive
- [ ] Tests + CI green; auto-merge; never commit to main
