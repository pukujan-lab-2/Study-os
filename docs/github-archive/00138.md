## Research/product question
Unblock the first learner screen: `fractions-compare` step 1 (`problem`) was a
probe-null teach-only card, so the player showed no Check button and no way
forward, and completed steps could not be revisited.

## What changed
- Step `problem` is now a real `choice` probe: `["3/4","2/3"]`, accept `3/4`,
  misconception `bigger-denominator-bigger` for `2/3`, with
  `correct_md`/`explain_md`/`hint_md`/`solution_md` and 2 variants that pass
  `check_lesson`.
- Incorrect feedback now includes the matched misconception note.
- Engine: teach-only steps expose `can_revisit_step`; new `engine.revisit`
  reopens an already-visited step (refuses unvisited targets).
- UI: teach-only steps get a Continue button (`next()`); `LessonMap` chips for
  visited steps are buttons that call the existing adapt path (`kind:
  "step_back"`), plus a Back affordance already present.
- Service/API: `adapt` accepts `kind: "step_back"` with optional `step_index`.
