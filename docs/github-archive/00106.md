## SOS-0009 research ready for review

**Doc:** [`docs/research/voice-robustness.md`](https://github.com/Pukujan/Study-os/blob/task/SOS-0009-voice-robustness-research/docs/research/voice-robustness.md) on `task/SOS-0009-voice-robustness-research` (PR incoming). SHA `efb5715`. SOS-0005 and production untouched.

### Recommended stack
| Layer | Choice | Fallback |
|---|---|---|
| Capture | Browser `echoCancellation` + `autoGainControl` on; `noiseSuppression` on but A/B; Silero VAD; push-to-talk; **no** ML denoiser by default | Opt-in DeepFilterNet3 with dry mix |
| STT primary | In-browser **Moonshine** (English MIT) or Whisper `small.en` via transformers.js, with lesson **hotwords/keyterms** | — |
| STT server | gravebuster **faster-whisper `small.en` + hotwords** (or **Parakeet-TDT-0.6B int8** via sherpa-onnx — best WER/RTF on our box smoke) | `base.en` under load |
| Grading | Normalise → exact/alias → Double Metaphone + fuzzy → MiniLM embedding → **Jev only when unsure** with filtered candidates | Always show editable transcript; "Did you mean X?" |
| TTS default | **Kokoro-82M** always warm (also kokoro-js in browser). Bright tutor: `af_heart` / `af_bella` or original 60/40 heart+jf_alpha blend | Device `speechSynthesis` last resort |
| TTS dropdown (lazy) | Pocket TTS (CC0/CC-BY voices only), Piper (PD/CC0 voices), Chatterbox **only if** gravebuster p95 ≤ 2.5 s/sentence | Router plays Kokoro while a cold engine warms; cache by (engine, voice, text) |
| **Excluded** | F5-TTS / XTTS-v2 (NC weights); Style-Bert-VITS2 (AGPL); GPT-SoVITS (cloning-centric); Distil-Whisper **with** hotwords (degenerated in our test) | — |

### Key findings
1. **Hotwords are the biggest win.** `small.en` HESI terms 13/21 → **21/21** (WER 10.5% → 0%) with the lesson glossary as hotwords [measured].
2. **Grade meaning, not transcripts.** Phonetic+fuzzy recovered 13→21/21 terms on clean unbiased `small.en` with 0 false positives on other vocab [measured]. EDM 2026: full-context LLM repair *hurt*; filtered phonetic context helped.
3. **Don't put a strong denoiser in front of ASR by default** (enhancement artifacts hurt ASR more than residual noise).
4. **Per-user LoRA:** papers show ~15–37% relative WER gains, but needs stored audio + GPU + per-user adapters. **Defer** until key-term error stays >~15% after biasing+matching.
5. **gravebuster** is Ryzen 7 5800U, **no NVIDIA**, ~10 GiB free RAM, load 30–51 during check — CPU-only, plan for contention; max one heavy TTS warm.
6. **Anime-style English without cloning:** Kokoro style-vector blend (original synthetic voice) + Pocket TTS CC0/CC-BY voices. No actor/character clones.
